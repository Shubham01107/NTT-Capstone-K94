Objective and statistics

Draw a hollow, one-pixel border box in the centre of the Hack screen using only machine instructions. The program calculates screen addresses, loops over memory words and sets individual bits, with no graphics library involved.

Part A: Hardware Description Language

The three top-level chips that turn instructions into screen updates.

How the chips work together

  • Memory.hdlAddress bits 14 and 13 select RAM (0 to 16383), Screen (16384 to 24575) or Keyboard (24576).
  • CPU.hdlDecodes A and C instructions, drives the ALU, loads registers and decides whether to jump.
  • Computer.hdlConnects ROM32K, CPU and Memory. A reset signal restarts the program at address 0.
  • Built-in partsALU, registers, PC, RAM16K, Screen, Keyboard and ROM32K are reused from earlier chips or the simulator.

Part B: Python two-pass assembler

Pass 1 maps labels to ROM addresses. Pass 2 allocates variables from RAM 16 and encodes each instruction.

Run the project

Test the hardware

Open the chips from hdl/ in the Nand2Tetris Hardware Simulator and compare them with the course test scripts.

Assemble the program

Run python assembler/assembler.py asm/Box.asm. It writes asm/Box.hack next to the source.

Draw the box

Load Box.hack into the CPU Emulator, turn animation off and run. The box appears in the centre of the screen.
